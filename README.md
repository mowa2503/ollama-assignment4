# Assignment 4: Comparing Two Local LLMs with Ollama

## Project overview

This project runs the **same prompts** through two different open language models on my own Mac using **Ollama** and the **Ollama Python library**. It saves each actual model response to a CSV file and records response times so the models can be compared.

**Important:** The results section is populated only when the script actually runs on the local Mac. No experimental results have been invented.

## Models used

1. **`llama3.2:1b`** — Meta's Llama 3.2, 1-billion-parameter variant (approximately 1.3 GB model download).
2. **`qwen2.5:1.5b`** — Qwen 2.5, 1.5-billion-parameter variant (approximately 986 MB model download).

These are relatively small models chosen for a Mac with **16 GB RAM**. They are different model families, not simply two copies of the same model.

Model pages: [Llama 3.2](https://ollama.com/library/llama3.2) and [Qwen 2.5](https://ollama.com/library/qwen2.5).

## Requirements

- macOS computer with Ollama installed and running
- Python 3.8 or newer, and `pip`
- The packages in `requirements.txt`
- Internet access to download the models once; inference is local thereafter

No paid AI account or API key is required.

## How to run

Open Terminal and enter the extracted project folder. On my Mac, the project is on the `Desktop`:

```bash
cd ~/Desktop/ollama-assignment4
```

Install the Python library in a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Make sure the Ollama app is open, then download both models:

```bash
ollama pull llama3.2:1b
ollama pull qwen2.5:1.5b
ollama list
```

Run the experiment:

```bash
python run_models.py
```

On success this creates **`model_outputs.csv`** and updates the measured-results table below. The generated CSV is the file to include with the project submission.

## Experiment design

The program sends **two prompts to each model** (four responses in total):

1. **`ai_vs_ml`**: Explain the difference between artificial intelligence (AI) and machine learning (ML) to a 14-year-old in exactly three sentences, with an everyday example.
2. **`arithmetic`**: Calculate how many pencils remain after starting with three packs of four and giving away five. The correct result is **7 pencils**.

Every model receives the exact same text for each test. The program uses temperature `0` and a maximum of `180` generated tokens. It measures end-to-end wall-clock time and also records Ollama's internal total duration and output-token count when available.

**CSV columns:** `timestamp_utc`, `prompt_id`, `model`, `prompt`, `response`, `wall_time_seconds`, `ollama_total_seconds`, `output_tokens`.

## My observations

**Speed:** For the AI-versus-ML prompt, Llama 3.2 took 2.73 seconds while Qwen 2.5 took 7.96 seconds, so Llama was faster in that test. For the arithmetic prompt, Qwen was slightly faster (0.51 seconds) than Llama (0.67 seconds). Model loading and other factors may affect these times, so I cannot conclude that one model is always faster.

**Correctness:** Both models correctly calculated that 3 packs of 4 pencils contain 12 pencils, and 12 minus 5 leaves **7 pencils**. I found no arithmetic mistake in either response. For the AI/ML question, both broadly explained that machine learning is related to AI, although their descriptions simplify how AI systems work.

**Clarity and instruction-following:** I found Qwen's chess-game analogy easy to follow for a 14-year-old. Llama explained more directly that machine learning is a specific type of AI and gave a video-game example. Llama followed the instruction to write exactly **three sentences**; Qwen wrote **five sentences** instead. Both included an everyday example. This shows that a clear answer does not necessarily follow every instruction.

**Comparison with commercial models:** I have used ChatGPT while learning and preparing this project, but I did not run the same prompts in a controlled comparison with ChatGPT. Therefore, I cannot make a measured claim that either local model is better or worse than a commercial model based on these results alone. Running the models locally did not require a paid AI service or an API key.

**Overall conclusion:** This experiment showed me that two small local language models can answer basic questions successfully, but their speed, style, and instruction-following can differ. Both solved the arithmetic problem correctly, while only Llama followed the three-sentence instruction in the AI explanation. More prompts and repeated runs would be needed for a fairer evaluation.

## Limitations

- Only two short prompts are tested, so this is a small educational comparison, not a scientific evaluation.
- Response times depend on the Mac's chip, available memory, whether the model was already loaded, and other running tasks.
- `temperature=0` helps reduce randomness, but exact output can still vary across versions and environments.
- These models are much smaller than many cloud-based commercial language models; however, quality differences must be evaluated using actual outputs rather than assumed.
